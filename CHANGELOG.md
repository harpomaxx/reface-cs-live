# Changelog

## 0.2.0

- Added a MIDI device selector to both performance and management screens.
- Remember the selected MIDI device across app restarts and USB reconnects.
- Keep automatic reface CS detection when no manual selection exists.
- Prompt for an explicit choice when multiple non-reface MIDI devices are available.

## 0.1.0

- Initial Android release with patch capture, recall, setlists, SysEx import/export, and library backups.
